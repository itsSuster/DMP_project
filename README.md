# DMP_project

SMART ALARM #1
 A smart alarm system using Arduino that detects nearby objects with an ultrasonic distance sensor. When an object gets too close, the buzzer activates to warn the user.

Components:
- Arduino Uno board
- Ultrasonic Distance Sensor (HC-SR04)
- Buzzer
- LEDs (red and green)
- Resistors
- Breadboard
- Jumper wires

Features:
- Detects objects using an ultrasonic sensor.
- Measures the distance between the sensor and an object.
- Activates the buzzer when an object is too close.
- Increases the beep frequency as the object gets closer.
- Uses LEDs to indicate safe and dangerous distances.
- Automatically stops the alarm when the object moves away.

  REACTION TIME GAME #2
  A simple Arduino-based game that tests the player's reaction speed. After a random delay, an LED lights up, and the player must press a button as quickly as possible. Arduino measures and displays the reaction time.

Components:
- Arduino Uno board
- LED
- Push button
- Resistor
- LCD display 
- Buzzer 
- Breadboard
- Jumper wires
  
Features:
- Turns on an LED after a random delay.
- Measures the player's reaction time in milliseconds.
- Displays the reaction time on an LCD or Serial Monitor.
- Detects early button presses (false starts).
- Provides sound feedback using a buzzer.
- Tracks the player's best reaction time.
- Allows the player to restart the game.

SMART PET FEEDER #3
 An Arduino-based automatic pet feeder that dispenses food at scheduled times. A servo motor controls a small opening mechanism, allowing food to fall into the pet's bowl.
 
 Components:
- Arduino Uno board
- Servo Motor
- RTC Module (DS3231)
- Food Container
- Push Button
- Breadboard
- Jumper Wires
- External Power Supply

 Features:
- Automatically dispenses food at scheduled times.
- Uses a servo motor to open and close the food container.
- Allows manual feeding using a push button.
- Supports adjustable feeding schedules.
- Controls the approximate food portion by adjusting the opening duration.
- Automatically closes the container after dispensing food.
- Optional LCD display showing the next feeding time.
